Installation & system requirements

Windows: run the portable EXE. Microsoft Edge WebView2 Runtime is required.

macOS: open the DMG and drag lazytune to Applications. Choose Apple Silicon for M-series Macs, or Intel for older Intel Macs.

Linux: DEB packages target Ubuntu 22.04 and compatible systems. RPM packages require WebKitGTK 4.1 and GStreamer codecs. Make an AppImage executable before opening it; FUSE 2 or --appimage-extract-and-run is required.

Preview releases are not Windows code-signed or Apple notarized. Your operating system may warn on first launch. Check the release notes and SHA-256 checksums before installing.

This is an early release. Google sign-in, playback, codecs, and desktop integration can vary by platform. YouTube Music’s account and subscription requirements still apply.
